실험 챗봇 사용 가이드

1. 개요

Redmine RAG 챗봇은 AI-DT팀의 실험 이력, 모델 성능, 알고리즘 설명, 주간보고 등 Redmine에 등록된 모든 이슈를 검색합니다.
Dense 벡터 검색 + BM25 키워드 검색을 결합한 하이브리드 방식으로 동작합니다.

2. 잘 검색되는 질문 작성법

구체적으로 질문할수록 정확한 답변을 받을 수 있습니다!

• 무엇을 알고 싶은지 명확하게 질문하세요 (성능? 하이퍼파라미터? 데이터셋?)
• 여러 버전 비교가 필요하면 "V0.12.1부터 V0.12.4까지 비교해줘" 처럼 범위를 명시하세요
• 후속 질문이 가능합니다 — "방금 말한 모델의 데이터셋은?" 처럼 이어서 질문하세요
❌ 검색이 잘 안 되는 질문
• "모델 성능 알려줘" → 어떤 모델?
• "최근 실험 뭐해?" → 누구의 실험?
• "하이퍼파라미터 알려줘" → 어떤 모델 어떤 버전?
✅ 질문 예시 (클릭하면 자동 입력됩니다)

1. 개요

CRF: 8개 암종, 다기관에서 수집된 임상 데이터 총 33,085건을 검색·통계·분석합니다.
암종별 바이오마커, 병기, 수술 정보, 재발 여부, 치료력 등 다양한 임상 필드를 지원합니다.

병원 필터 안내
질문에 아래 병원명을 포함하면 해당 병원 데이터 위주로 검색됩니다.
• 세브란스 (연세 / 신촌세브란스)  |  계명대  |  분당차 (차병원 / 차의과)
• 강남세브란스  |  강남차  |  단국대  |  이화여대 (이대목동 / 이화 / 이대)
※ 병원 필터는 유방암·갑상선암·자궁경부암·간암에서 안정적으로 동작합니다.
위암·대장암·난소암(HRD)·전립선암은 기관 메타데이터 형식이 균일하지 않아 병원명 필터 정확도가 제한될 수 있습니다.
암종별 데이터 현황 (총 33,085건)
• 유방암 (Breast): 9,055건 — 병원 01~07
• 위암 (Stomach): 8,414건 — 다기관 수집 (병원 메타 정규화 진행 중)
• 갑상선암 (Thyroid): 8,144건 — 병원 04
• 대장암 (Colorectal): 1,854건 — 병원 메타 정규화 진행 중
• 난소암 HRD (HRD): 1,754건 — 다기관 (기관 식별자 형식 다양)
• 자궁경부암 (Cervix): 1,741건 — 병원 04, 05
• 전립선암 (Prostate): 1,671건 — 병원 01
• 간암 (Liver): 452건 — 병원 02, 03, 04
Record ID 접두어 (암종별)
• BC_병원_번호 : 유방암  |  TC_병원_번호 : 갑상선암

1. 로그인 및 계정 초기설정

  • 첫 로그인 후 우측 상단 → 내 계정 (My account) 에서 아래 항목을 먼저 설정하세요.
    • 비밀번호 변경
    • 언어 / 시간대 설정
    • 메일 알림 수신 범위 설정
  • 비밀번호를 잊어버린 경우: 로그인 화면 → 비밀번호를 잊으셨나요?
일부 메뉴나 프로젝트가 보이지 않으면 계정 문제가 아니라 권한/역할이 아직 부여되지 않은 경우가 많습니다. 관리자 또는 프로젝트 관리자에게 멤버 추가를 요청하세요.

2. 프로젝트 생성

  • 상단 메뉴 프로젝트 → 새 프로젝트
  • 이름, 식별자(identifier), 설명 입력
⚠️ 식별자(identifier)는 URL에 사용되며 생성 후 수정 불가합니다. 프로젝트 구조를 고려해 신중하게 입력하세요.
  • 공개 여부: 비공개 권장 (내부 업무 기준)
  • 생성 후 바로 확인: 설정 → 모듈 (이슈/Wiki/Files 활성화), 설정 → 멤버 (팀원 추가)
  • 프로젝트 구성 기준: 프로젝트 → 연구 주제·암종 단위 / 이슈 → 개별 실험·회의·보고 단위

3. 이슈 작성 및 업데이트

  • 프로젝트 내 이슈 → 새 이슈
  • 작성 시 입력 항목: 제목 / 설명 / 담당자 / 우선순위 / 상태 / 마감일 / % 완료
  • 이슈 설명에 포함하면 좋은 내용: 실험 목적 / 사용 데이터 및 버전 / 모델·파라미터 / 주요 결과 / 후속 작업
  • 상태 흐름 권장: 초기 → 진행중 → 완료

4. 첨부파일 및 이미지 삽입

  • 이슈 작성 시 하단 파일 영역에서 첨부 (결과 이미지, 표, PDF 등)
