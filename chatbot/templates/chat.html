1. 개요

Redmine RAG 챗봇은 AI-DT팀의 실험 이력, 모델 성능, 알고리즘 설명, 주간보고 등 Redmine에 등록된 모든 이슈를 검색합니다.
Dense 벡터 검색 + BM25 키워드 검색을 결합한 하이브리드 방식으로 동작합니다.

2. 잘 검색되는 질문 작성법

구체적으로 질문할수록 정확한 답변을 받을 수 있습니다!

• 무엇을 알고 싶은지 명확하게 질문하세요 (성능? 하이퍼파라미터? 데이터셋?)
• 여러 버전 비교가 필요하면 "V0.12.1부터 V0.12.4까지 비교해줘" 처럼 범위를 명시하세요
• 후속 질문이 가능합니다 — "방금 말한 모델의 데이터셋은?" 처럼 이어서 질문하세요
❌ 검색이 잘 안 되는 질문
• "모델 성능 알려줘" → 어떤 모델?
• "최근 실험 뭐해?" → 누구의 실험?
• "하이퍼파라미터 알려줘" → 어떤 모델 어떤 버전?
✅ 질문 예시 (클릭하면 자동 입력됩니다)

7. 제한사항

답변하기 어려운 질문
• 미래 계획에 대한 질문 (예: "다음 실험 뭐하지?")
• Redmine에 등록되지 않은 내용
• 코드 생성 요청 (예: "학습 코드 작성해줘")
• 너무 짧거나 애매한 질문 (예: "이거", "성능")
• 모델명 없이 모호하게 질문하는 경우
• 기획팀 이슈 조회 시 질문에 '기획' 키워드를 포함해야 합니다

8. 도식화 및 복사 기능

📋 답변 복사
• 답변 하단 "📋 답변 복사" 버튼 클릭 시 참고 이슈를 제외한 답변 본문만 클립보드에 복사됩니다.
• 복사 후 다른 문서나 메신저에 바로 붙여넣기 가능합니다.

📄 일반 도식화 생성
• 답변 내용을 기반으로 알고리즘 파이프라인, 실험 흐름, 모델 구조 등을 자동으로 도식화합니다.
• 실험 결과 비교, 수치 데이터가 있는 답변에도 적용 가능합니다.

📝 특허 도식화 생성
• 답변 내용을 특허 청구항 계층 구조(Claim 1, 2, 3...) 형태로 도식화합니다.
• 기술 특허 출원 자료 작성 시 활용하세요.

⏱ 소요 시간: 도식화 생성은 1~3분 정도 소요됩니다. 진행 상태가 실시간으로 표시됩니다.

🖼 이미지 확인
• 답변 하단 참고 이슈에서 [IMG n] 표시가 있는 이슈를 선택하면 관련 이미지 썸네일이 함께 표시됩니다.

9. 참고 사항

Redmine 연동:
• 답변 하단 "참고 이슈" 링크 클릭 시 Redmine 원본 이슈로 이동합니다.
• 정확한 수치나 상세 내용은 반드시 원본 이슈를 확인하세요.

• 질문 시 암종명을 명시하면 더 정확한 답변을 받을 수 있습니다.
• 예: "유방암 환자 중 ~", "위암 데이터에서 ~", "갑상선암 ~"

후속 질문:
• 이전 답변을 기억하므로 "방금 그 중에서 재발한 환자만 보여줘" 같은 후속 질문이 가능합니다.
